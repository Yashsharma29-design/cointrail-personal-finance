# Cointrail Personal Finance

Prompt: Build CoinTrack Frontend UI

Act as an expert frontend developer and UI/UX designer. Build a modern, premium-looking, responsive frontend for a personal finance management application named CoinTrack.

The application helps users track income and expenses, update transactions, receive payment requests, send money, and monitor their financial activities.

Important: Build only the frontend. Do not configure a backend, database, Supabase, or real payment gateway. Use realistic mock data and localStorage to simulate user interactions and preserve demo data after refreshing the page.

1. Technology Stack

React with TypeScript

Vite

Tailwind CSS

React Router for navigation

Lucide React for i
